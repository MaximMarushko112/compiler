# C-lite компилятор

Проект учебного компилятора для языка C-lite (подмножество C). Реализованы лексический, синтаксический анализ, построение AST, визиторы для печати, интерпретации и анализа областей видимости с проверкой типов.

## Требования

- CMake 3.15 или выше
- Компилятор с поддержкой C++20 (GCC 10+, Clang 12+, MSVC 2019+)
- Make (или любой генератор, поддерживаемый CMake)

## Сборка

1. Склонируйте или скопируйте исходные файлы.
2. Создайте директорию для сборки и перейдите в неё:
   ```bash
   mkdir build && cd build
   ```
3. Сгенерируйте систему сборки:
   ```bash
   cmake ..
   ```
4. Выполните сборку:
   ```bash
   make -j$(nproc)
   ```

## Запуск

После сборки в директории `build` появится исполняемый файл `c_lite_test`. Запустите его:

```bash
./c_lite_test
```

Программа выполнит набор тестов, демонстрирующих работу токенизатора, парсера, печати AST, интерпретатора и анализа областей видимости с проверкой типов.

## Структура проекта

- `include/` – заголовочные файлы:
  - `Tokenization/` – токенизатор.
  - `Parsing/` – AST, парсер, визиторы (интерфейс).
  - `Visitors/` – конкретные визиторы (интерпретатор, проверка областей видимости, печать).
- `src/` – исходные файлы, соответствующие заголовкам.
- `CMakeLists.txt` – файл сборки.

## Особенности реализации

- AST построено на иерархии классов с поддержкой визитора.
- Интерпретатор выполняет базовые арифметические операции, условные операторы, циклы, вызов функций (`print` и пользовательские функции).
- ScopeVisitor строит дерево областей видимости, проверяет повторные объявления, использование необъявленных переменных и совместимость типов.
- Типизация выражений осуществляется через виртуальный метод `getType()` в классах выражений (литералы, унарные/бинарные операции) и через таблицу символов для переменных и вызовов функций.

## Пример вывода

При запуске тестов выводятся токены, AST, результаты анализа областей видимости и работы интерпретатора (например, факториал числа 5).

## Примечание

Для очистки сборки выполните в директории `build`:

```bash
rm -rf *
```

Затем повторите шаги сборки.
